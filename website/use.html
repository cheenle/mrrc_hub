三个入口怎么选

同一台电台、同一套口令，可以从三个地方进去。默认永远选第一个。

入口 地址 什么时候用
主路 https://<呼号>.mrrc.vlsc.net:9988/ 默认选它。低延迟，真证书。 2026-10-01 多次实测全部成功，往返 0.3–0.5 s。
主路备用口 https://<呼号>.mrrc.vlsc.net:8899/ 与 9988 是同一个服务、同一张证书。 只有你的网络单独放行了这一个端口时才需要它。
海外边缘 https://www.vlsc.net/mrrc_modern/<呼号大写>/ 只放行 80/443 的网络（公司网、访客 Wi-Fi）。 本节下方有它的实测问题，用之前先读。
局域网 http://<内网IP>:8888/ 在家。不经过 Hub，延迟最低。
边缘入口的路径必须用大写呼号

URL 路径是大小写敏感的，而 DNS 不敏感。 写成小写 /mrrc_modern/bg1sb/ 会被 301 到规范形式 /mrrc_modern/BG1SB/ —— 能通，但多一次跳转。 分享链接时直接给大写形式。

海外边缘入口实测存在间歇性失败（2026-10-01）

实测 6 次请求中有 3 次在 20 秒内完全没有响应（另外 3 次约 0.5 s 正常返回）， 呈交替出现。已排除的原因：本地 DNS/TCP/TLS 均正常（0.2 s 内完成）、 www 的静态服务 6/6 正常、www 上另一条代理腿 6/6 正常、 hub 侧各种 SNI/Host 组合 6/6 正常。失败发生在 www → hub:9988 这一跳。

因此把它当作备用路径：先用主路，主路不通再试它，不要把它当默认。 该问题已记录在案，待进一步取证。

两把口令，两个角色

这是最容易搞错的地方：同一个登录页，口令不同，进去之后的权限完全不同。

口令 从哪进 听 看频谱 调频 / 换模式 发射
主口令 / ✓ ✓ ✓ ✓
监听口令 /listen ✓ ✓ ✓ ✗ 服务端拒绝
"不能发射"是服务端强制的，不是界面藏起来

监听角色在服务端被限制为只读：所有改变状态的接口调用都会被直接拒绝， 它连接的数据通道里压根不包含发射音频那一条。 所以把监听口令给别人是安全的 —— 对方拿不到发射权，不是"界面上找不到按钮"而已。

监听口令默认是空的 = 监听角色进不去

如果你还没设置监听口令，那这个角色无法进入（空口令永远不匹配）。 想分享给别人之前，先去实例上把它设好。

监听者能调频，这是刻意的

监听者可以调频率、换模式、调用存储频道，只是不能发射。 这不是疏忽 —— 因为"调频"并不改变"谁在发射"这个根本约束， 而禁止调频会让想帮忙找台的人完全帮不上忙。

分享给朋友

给这两样
  • 入口地址（主路优先）：https://<呼号>.mrrc.vlsc.net:9988/
  • 监听口令 —— 对方能听、能看频谱、能调频，不能发射
别给主口令

主口令等于发射权。给了主口令，对方就能按下 PTT —— 这是在你的呼号下发射。而且现阶段 Hub 侧还没有细粒度的成员管理， 你也没法事后单独撤销某个人。

现状与已知退化

下面这些是现状，不是设计。写出来是为了让你在遇到时不会以为是自己的配置错了。

事项 状态
独占写者租约（每个实例同时最多一个操作者） 未实现 · 阶段 2
两个人同时用主口令登录时，谁在发射由实例侧仲裁： 只有当前那个"占有发射权"的会话能按下 PTT。
成员管理与单独撤销 未实现 · 阶段 2
想收回某个人的访问权，只能改监听口令（会影响所有拿到它的人）。
注：实例级的撑销已有流程（冒用被核实后可移除绑定并停用入口）， 但它是针对整个呼号的，不能拿来单独停掉某个监听者。
登录失败限流 已知退化
限流规则是 5 次失败 / 300 秒。但在隧道方式下， Hub 看到的所有登录都来自同一个来源，于是限流退化成全局桶 —— 别人反复输错口令，会把你自己的登录一起锁住 5 分钟。已决定暂缓修。
PTT 释放 已实现
不依赖云端。关浏览器、掉线、拔网线、换 Wi-Fi， 一律由电台所在那台机器本地强制回到接收。 另有发射时长硬上限兜底。
deploy/*.sh 与现网漂移 已记录未修
仓库里的 deploy_hub_routes.sh 与 deploy_www_edge.sh 落后于现网配置： 重跑会把 8899 从 TLS 退回明文、把海外边缘入口形态降级。 自己跑本仓脚本前，先读 deploy/README.md 的「脚本与现网漂移」一节。
别把主口令发进群

因为上面那条"全局桶"：群里有人反复输错你给的主口令， 会把你自己也一起锁在门外 5 分钟。分享用监听口令。

手机上用

  • 当 App 用 —— 用手机浏览器打开入口，选"添加到主屏幕"。 打开后是全屏的，和原生 App 观感接近。
  • 原生 App —— MRRC Modern 有 iOS 客户端， 下载与配置见产品站。
  • 切网络会自动重连 —— 隧道带 KeepAlive，从 Wi-Fi 切到蜂窝会自己恢复， 不用手动重启任何东西。
